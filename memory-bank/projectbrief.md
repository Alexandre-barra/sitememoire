# Project Brief - Site Mémoire (Collecte de Noms)

Ce projet consiste à créer un site internet simple, fun et interactif permettant de collecter les informations des personnes (Prénom, Nom, Surnom, Pseudo) afin de les intégrer dans la page de remerciements du mémoire de l'auteur.

## Objectifs principaux
- Offrir une interface d'enregistrement simple et amusante.
- Jouer une musique d'ambiance en arrière-plan (avec contrôle utilisateur Play/Pause).
- Afficher un effet visuel festif lors de la validation (confettis + GIF transparent).
- Stocker localement les données collectées et fournir un moyen de les exporter (format JSON/CSV).

## Exigences UI/UX
- Design moderne et chaleureux (palette OKLCH soignée, typographie harmonieuse).
- Pas de surcharge visuelle, mais une esthétique "fun" et engageante.
- Accessibilité et réactivité mobile.
